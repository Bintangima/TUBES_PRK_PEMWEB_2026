# 📁 Direktori Kelompok Tugas Besar Pemrograman Web

Silakan **Fork** repository ini dan buat folder baru di dalam direktori `kelompok/` ini sesuai dengan nomor kelompok masing-masing.

### ⚠️ Aturan Penamaan Folder (Wajib Diikuti agar Lolos CI/CD):
1. Gunakan **huruf kecil semua (lowercase)** dan **dua digit angka** dengan pemisah *underscore* (`_`).
   - ✅ **Benar:** `kelompok_01`, `kelompok_02`, `kelompok_10`
   - ❌ **Salah (Akan Ditolak Bot):** `Kelompok_01`, `kelompok_1`, `kelompok 01`, `kelompok-01`
2. **DILARANG** mengubah atau menghapus file `README.md` ini, file di luar folder `kelompok/`, ataupun file milik kelompok lain.
